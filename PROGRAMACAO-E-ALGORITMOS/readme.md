# 💻 Programação e Algoritmos

## 📌 Descrição
Estudo da lógica de programação e desenvolvimento de soluções computacionais por meio de algoritmos e código.

## 🎯 Objetivo
Desenvolver o raciocínio lógico e aprender a programar para resolver problemas de forma eficiente.

## 📚 Conteúdos
- Lógica de programação
- Algoritmos
- Fluxogramas
- Pseudocódigo
- Variáveis
- Condicionais
- Laços de repetição
- Funções

## 📝 Atividades
- Exercícios de lógica
- Desenvolvimento de algoritmos
- Programas simples
- Projetos práticos

## 📂 Materiais
- Caderno
- IDE / ambiente de programação
- Exercícios
- Anotações

## ⚠️ Observações
Entender a lógica é mais importante do que decorar código.
Prática constante é essencial.
